## PROJECT IN ONE PARAGRAPH

`pitwall_sim` (product name: **We Are Racing, Not Testing**) is a single-user desktop 2D Formula 1 race simulator built in Python 3.13 + PySide6, faithful to the 2026 power unit regulations (~50% combustion engine, ~50% MGU-K electric). The user is the race engineer of one car (Our Car). The simulator holds Ground Truth for all 22 cars, including hidden battery energy. In race, the user sees Our Car exactly but sees Rivals only through public timing, noisy 4 Hz telemetry (Public Feed) and a Radar Estimate of their battery. The user issues Engineer Commands by buttons or free-text radio (local fine-tuned Gemma 3 270M model). After the race, a debrief compares the user's calls with the best calls. Real 2026 races can be replayed in compare modes.

## HARD RULES

Violating any of these is a defect, regardless of tests passing.

| ID | Rule |
| --- | --- |
| HR-01 | `pitwall_sim/race/`, `pitwall_sim/car/`, `pitwall_sim/track/`, `pitwall_sim/driver/` MUST NOT import PySide6, `pitwall_sim.ui`, or `pitwall_sim.radio`. The simulation core runs headless. |
| HR-02 | `pitwall_sim/ui/` MUST receive race data only as `EngineerView` (`pitwall_sim/observe/engineer_view.py`). It MUST NOT import `pitwall_sim.race.state`. Enforced by import-linter contract `ui-info-barrier`. |
| HR-03 | Rival Ground Truth (`battery_mj`, `energy_mode`, `tyre_wear`, `fuel_kg`, `RivalPlan`) MUST NOT reach any in-race view, Rival Strategy AI of another team, or the Strategy Predictor. |
| HR-04 | All randomness MUST come from the named RNG streams in `race/snapshot.py` (`overtake`, `mistakes`, `events`, `weather`, `pit`, `feed_noise`, `rival_strategy`, `predictor`). No `random` module, no unseeded NumPy, no wall-clock time in simulation logic. |
| HR-05 | No 2026 rule number may be hard-coded. Rule values come from `config/rules/<rule_set>.yaml`. Team, tyre, track and calibration coefficients come from config. |
| HR-06 | Code MUST reference `team_id` / `driver_id`, never display names (grid is switchable real ↔ fictional). |
| HR-07 | Gemma output MUST pass through `engineer/commands.validate()` before execution. The LLM never changes race state directly. |
| HR-08 | The physics step MUST NOT be skipped to keep up with the clock. Slow down effective clock speed instead. |
| HR-09 | Do not invent values marked `UNKNOWN` or `UNRESOLVED` in the docs. Use a clearly named placeholder in config (`# PLACEHOLDER: calibrate`) and list it in the task report. |
| HR-10 | Do not add features outside the current release in `docs/spec/MVP.md` unless the task says so. |

## CODE CONVENTIONS

| Item | Convention |
| --- | --- |
| Formatting / lint | `ruff format`, `ruff check` (config in `pyproject.toml`) |
| Types | Type hints on all public functions; `mypy --strict` SHOULD pass for `pitwall_sim/` except `ui/` |
| Data contracts | `@dataclass` as defined in `docs/spec/TRD.md` DATA CONTRACTS; do not rename fields |
| Config models | pydantic v2 models in `pitwall_sim/config/models.py`, one per YAML schema |
| Units | SI internally (m, s, kg, W, J, m/s). Convert to km/h, kW, MJ only at UI and config boundaries. Suffix names with unit: `v_ms`, `p_k_kw`, `battery_mj` |
| Hot loop | Numba `@njit` over parallel NumPy arrays in `race/step_kernel.py`; no Python objects inside |
| Logging | `logging` module; no `print` in library code |
| Tests | `tests/unit`, `tests/integration`, `tests/ui`; fixtures use seed `42` unless a test needs others |
